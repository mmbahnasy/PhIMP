# myAIMSIncidentManagement
AIMS Incident Management Platform Criteria for Pharmacies

A simple pharmacy incident management portal for documenting medication incidents, tracking CQI action plans, and preparing anonymized NIDR submissions.

This project is a work in progress and is not yet configured to submit live data to the National Incident Data Repository for Community Pharmacies (NIDR).

Required libraries:
- Flask
- PyYAML
- Requests

To run the application:
1. Open a terminal in the project folder.
2. Install the dependencies: `pip install flask pyyaml requests`
3. Start the app: `python main.py`
4. Open http://127.0.0.1:5000 in a browser.
